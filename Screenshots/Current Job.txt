Job Title: Senior Technical Consultant (MDM Full Stack)

1. The Infrastructure Stack (Linux & Middleware)

The Senior Tech Con is responsible for the "health and feeding" of the application environment.
OS: Expert-level Linux (RHEL/CentOS) navigation. You aren't just a user; you manage services (systemctl), analyze disk I/O (df -h, iostat), and manage permissions (chmod/chown) for complex directory structures like /harris/metersense/files/.
Middleware: Configuration and tuning of Apache Tomcat. You manage the web layer, SSL/TLS certificate installation, and SAML/SSO integration (Option 2 and 3).
Automation: Writing and maintaining shell scripts (.sh) for "Hard Refreshes," automated backups, and log rotation.

2. The Data Stack (PostgreSQL / Oracle)

This is the heart of the role. You are essentially a Production DBA.
Advanced SQL: Writing complex queries to identify data gaps, duplicates, and synchronization errors.
Performance Tuning: Analyzing execution plans, rebuilding indexes, and managing tablespaces.
ETL & Integration: Managing DataSync (CIS-to-MDM). You must understand how to map source views (like Cayenta or NorthStar) into the Compass ODS (Operational Data Store).
Schema Management: Executing and troubleshooting major version upgrades (e.g., Compass 5.0 to 5.1) and handling unique constraint violations (_p1 errors).

3. The Logic Stack (Rules Engine)

You are a "Low-Code" Developer.
Business Logic: Designing and implementing automated workflows using the Compass Rules Engine.
VEE (Validation, Estimation, & Editing): Configuring the math that determines if a meter read is "good." This requires understanding utility-specific logic like ContinuousUsage, RegisterIncreasing, and Gap Filling strategies.
Event-Driven Architecture: Setting up rules that trigger based on AMI events (e.g., a "Leak" event triggering a Service Order in the CIS via MultiSpeak).

4. The Integration Stack (APIs & Protocols)

You are the bridge between different utility systems.
MultiSpeak: Expert knowledge of MultiSpeak 3.0/4.1 (SOAP/XML). You troubleshoot real-time web service calls between the MDM, the AMI (Sensus/Itron), and the CIS (Cayenta).
CMEP: Understanding the California Meter Exchange Protocol for flat-file meter data ingestion.
AMI Knowledge: Understanding how Head-End Systems (HES) communicate with meters to troubleshoot On-Demand Reads (ODR) and Remote Connect/Disconnect.
